# 🔳 Custom QR Code Generator

A simple Python program that generates **custom QR codes** from text or website URLs. It allows you to customize the QR code color, background color, size, and border.

## ✨ Features

* 🔗 Generate QR codes from text or URLs
* 🎨 Custom QR code color
* 🖼️ Custom background color
* 📏 Adjustable QR code size
* 🧱 Adjustable border size
* 💾 Saves the QR code as a PNG image
* 🔐 Uses high error correction

## 🛠️ Technologies

* Python
* `qrcode`
* `Pillow`

## 📦 Installation

Install the required libraries:

```bash
pip install qrcode[pil] pillow
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone .git
```

2. Open the project folder:

```bash
cd QR-code
```

3. Run the Python program:

```bash
python QR-code.py
```

4. Enter your text or website URL when prompted:

```text
Enter text or website URL: https://google.com
```

5. The QR code will be saved as:

```text
custom_qr.png
```

## 📌 Example

```text
Enter text or website URL: https://google.com
✅ QR code saved as custom_qr.png
```
